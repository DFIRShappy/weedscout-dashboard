# WeedScout beginner starter files

These scripts support **Sessions 9, 10 and 14** in the online workshop.

Save all three Python files into `Documents/WeedScout/02_code` on the student's Windows computer. On GitHub, open a file, click **Raw**, then use the browser's **Save As** command to keep its exact `.py` name. Use the virtual environment built in Session 8.

1. Generate an example target image: `.\.venv\Scripts\python.exe make_sample.py`
2. Detect its center: `.\.venv\Scripts\python.exe find_blue_marker.py sample_target.png`
3. Print cautious decisions: `.\.venv\Scripts\python.exe safe_decision_demo.py`

**No connected robot, camera, or actuator is required.** These are indoor practice simulations, not real weed detection or autonomous removal. Keep your copies and the results on your own computer; this public repository contains only starter scripts.
